# JOURNAL-IA — Mini-TP 4

- Variante de mise en page demandee a l'IA : le code original utilise Column dans Card pour afficher les infos verticalement. L'IA a propose d'utiliser Row a la place pour mettre le nom et le stock cote a cote.

- Mon verdict : je garde ma version avec Column car elle est plus lisible et le titre, l'origine et le prix sont presents dans un ordre naturel de haut en bas. La version Row rend la chose plus compliquee avec des poids et des modifier et c'est moins clair pour un debutant.

- Ce que j'en retiens : Row c'est bien pour afficher des elements horizontaux mais Column reste plus logique quand on a plusieurs elements qui se suivent.
